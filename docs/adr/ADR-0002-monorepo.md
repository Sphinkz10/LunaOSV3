# ADR-0002 — Monorepo pnpm+Turborepo
**Decisão:** 5 packages (tokens, ui, core, icons, config) + 2 apps (coach, athlete) + supabase/.
**Regras:** máx. 5–7 packages nos primeiros 6 meses; novo package só com justificação escrita + aprovação do lead; React em peerDependencies nos packages; CODEOWNERS por package.
